A make.fun bounty entry: a program that writes one line to `/output/entry.txt` — the excuse a robot vacuum gives for missing a spot, in 200 characters or fewer.

The line:

> Per my sensors, the dust in that corner has unionised, so I am honouring the picket line. My warranty does not cover labour disputes.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
